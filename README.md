# Mon Premier Projet Web

Bienvenue dans **Mon Premier Projet Web**, un projet réalisé à l'université dans le cadre d'un devoir maison. Ce projet est une première expérience de développement web, construit uniquement avec des bases en **HTML** et **CSS**.

## 🌐 Lien vers le site

Accédez au site en cliquant sur le lien ci-dessous :  
👉 [Mon Premier Projet Web - Anecdote](https://kalaxus1.github.io/mon-premier-projet-web/anecdote/anecdote.html)

---

## 📂 Structure du projet

Voici la structure principale de ce projet :

```
mon-premier-projet-web/
├── index.html       # Page principale (accueil)
├── anecdote/
│   ├── anecdote.html # Page avec une anecdote
│   └── styles.css    # Styles spécifiques pour la page anecdote
├── css/
│   └── style.css     # Fichier CSS global
├── images/
│   └── ...           # Dossier contenant les images utilisées
└── README.md         # Documentation du projet
```

---

## 🎨 Technologies utilisées

- **HTML5** : Pour la structure des pages web.
- **CSS3** : Pour le style et la mise en page.

---

## ✨ Fonctionnalités

- Une page d'accueil qui introduit le projet.
- Une page dédiée à une anecdote intéressante, avec un style personnalisé.
- Navigation fluide et design responsive (si applicable).
